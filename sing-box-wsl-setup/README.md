# WSL — исторический каталог

Файлы этого каталога описывают прежний WSL/Linux TUN/mixed-proxy подход. **Не действующий сценарий установки, восстановления либо настройки Windows.** Исторические команды, пути, selector/port значения и режимы могут не соответствовать текущему приложению; не применять их к `C:\sing-box`.

Нормативные документы: [архитектура](../edge-platform/ARCHITECTURE.md), [единственный план](../edge-platform/FINALIZATION-PLAN.md), [команды](../edge-platform/COMMAND-INVENTORY.md); технические ограничения Windows — [LOCAL-ARCHITECTURE.md](../win/docs/LOCAL-ARCHITECTURE.md). Физические свидетельства — [Issue #26](https://github.com/iamaman11/sing-box/issues/26).

Каталог оставлен только для определения и последующего удаления реально неиспользуемых исторических файлов; он не даёт разрешения на WSL/SSH/systemd/route mutation.
